# market-trends

A股指数均线偏离 / 股指期货基差滚动分位 / 宽度与情绪看板，每个交易日收盘后自动更新。

固定入口: https://saiwen11.github.io/market-trends/charts/index.html

## charts/
- daily_broad.html        日频 · 四大宽基（上证50/沪深300/中证500/中证1000）MA10/20/60 偏离 + 历史极值与当前分位表
- daily_three.html        日频 · 三大指数（上证指数/创业板指/科创50）
- weekly_three.html       周频 · 三大指数（每周最后一个交易日）
- weekly_broad.html       周频 · 四大宽基
- futures_basis_pct.html  股指期货基差率滚动历史分位（IF0/IH0/IC0/IM0）
- trin_dashboard.html     TRIN 严格日级看板
- mcl_dashboard.html      MCL 麦克连摆动指标
- concentration.html      市场成交额集中度（前5%个股，日月合并）
- sentiment.html          市场情绪仪表盘（综合情绪分）

数据截至: 2026-11-20（最近交易日）

本仓库内容为客观统计展示，不构成投资建议。
