# market-trends

每个交易日收盘后自动更新的市场图表（GitHub Pages 静态发布）：

- `charts/index.html` 导航首页
- `charts/daily_broad.html` 日频四大宽基指数 MA 偏离
- `charts/daily_three.html` 日频三大指数 MA 偏离
- `charts/weekly_three.html` 周频三大指数 MA 偏离
- `charts/weekly_broad.html` 周频四大宽基 MA 偏离
- `charts/etf_512890_weekly.html` 512890 红利低波 ETF 周频偏离
- `charts/futures_basis_pct.html` 股指期货基差率滚动分位
- `charts/trin_dashboard.html` TRIN 日级看板（严格TRIN + 全市场宽度）

固定网址: https://saiwen11.github.io/market-trends/charts/
